
# 🌦️ Weather App

A modern and responsive weather application built with **Python and Flask**, powered by the **OpenWeather API**. Get real-time weather information for cities around the world through a clean and intuitive interface.

## ✨ Features

- 🌍 Search weather for cities worldwide
- 🌡️ Real-time temperature and feels-like temperature
- ☁️ Dynamic weather conditions and icons
- 💧 Humidity, wind speed, and atmospheric pressure
- 🌅 Sunrise and sunset timings
- 🏳️ Full country names instead of country codes
- 🔔 Interactive flash notifications
- 📱 Responsive and modern user interface

## ⚙️ Installation

**1. Clone the repository**

```bash
git clone https://github.com/salmanshamir/weather-app.git
cd weather-app
```

**2. Create and activate virtual environment**

```bash
python -m venv venv
venv\Scripts\activate
```

**3. Install dependencies**

```bash
pip install -r requirements.txt
```

**4. Configure environment variables**

Create a `.env` file in the project root:

```env
API_KEY=your_openweather_api_key
```

Get your API key from [OpenWeather](https://openweathermap.org/api).

**5. Run the application**

```bash
python app.py
```

Visit `http://127.0.0.1:5000/` in your browser.

## 🔐 Security

Keep your API key private. Never upload your `.env` file to GitHub.
